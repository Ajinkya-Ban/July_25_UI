Background
---------------------
1. background-color:
---------------------------------
Background color has one drawback you can select only one color at time.
But my requirement i want to select multiple color at a time than i can use the property 
called as background-image.

1. background-image --> it will assign background image on the browser
2. background-image --> linear-gradient() --> This function can be used for to select  multiple colors.

Syntax:
---------------------
linear-gradient(direction/degree, colors)
directions ---> to right, to left, to bottom, to top
colors --> hexadecimal color, color name, rgb, rgba,

2. background-image --. url(image path)
3. background-repeat --> default is repeat. no-repeat, repeat-x, repeat-y
4. background-size--> contain, cover and you can use width and height in percentage
5. background-attachment --> scroll, fixed
6. background-position : right, left, top, center
