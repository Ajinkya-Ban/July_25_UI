What is mean by flex in css?
--------------------------------------
- Flex is one type of tool that can be used for to make each box flexible.
- Flex can work on only one direction at a time, like either in row direction or  in column direction.
- For arranging the we use float property, but by using flex we avoid float property.

For learning the flex we know some properties of flexbox. 

1. display:flex --> default direction row 

2. flex-direction --> default row, you can change direction like column, row-reverse, column-reverse


3. justify-content: justify content works on horizantal direction. justify content contains some properties like
    a) flex-start
    b) flex-end
    c) flex-center
    d) space-between
    e) space-around
    f) space-evenly

4. align-items:
-------------------------------
This properties work on vertical direction.
a) flex-start
b) flex-end
c) center
d) stretch(default)



5. align-content: 
-------------------------
This will work on multiple rows
    a) flex-start
    b) flex-end
    c) center
    d) space-between
    e) space-around
    f) space-evenly

6. flex-wrap : default nowrap, wrap, wrap-reverse
7. flex-grow : It adjust the extra space with providing equal width to single element.
This property will work on child elements

flex-grow : 1

You can also use 
flex-grow:2 ---> separate element



8. order:
-------------------------
To change the postion of the element on the basis of device.

This property will work on single element.
To maintain the order we use two types of values.
a) negative --> left side --> -1, -2
b) positive --> right side --> 1, 2,5



9. align-self:
--------------------------
This property will work on single element. 
a) flex-start
b) flex-end
c) center
d) stretch(default)

----------------------
To adjust the width of element.
